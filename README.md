# 📌 CadastroClientesAPI  
🚀 API para Gerenciamento de Clientes  
📖 Arquitetura: CQRS + Clean Architecture + MediatR

---

## 🏗 Sobre o Projeto
Esta API foi desenvolvida seguindo os princípios da **Clean Architecture** e **CQRS (Command Query Responsibility Segregation)**, utilizando o **MediatR** para comunicação entre os domínios. Ela permite **cadastrar, atualizar, listar e excluir clientes**, além de gerenciar seus logradouros.

---

## 🛠 Tecnologias Utilizadas
- **.NET 7 / .NET 6**
- **ASP.NET Core Web API**
- **Entity Framework Core**
- **SQL Server**
- **MediatR** (para CQRS)
- **Swagger**
- **FluentValidation**
- **AutoMapper**

---

## 🏛 Arquitetura do Projeto
O projeto segue os princípios da **Clean Architecture**, dividindo responsabilidades em camadas
